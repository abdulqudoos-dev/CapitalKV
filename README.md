# CapitalKV

> **Built by [Abdul Qudoos](https://www.abdul-qudoos.com)**, AI Automation & Forward Deployed Engineer · [More projects](https://www.abdul-qudoos.com/work)

A full-stack platform with a FastAPI backend and a Next.js frontend.

The backend (`backend/app/`) is organised into modules for auth, users, payments, e-commerce, campaigns, affiliate marketing (links, clicks and sales), real-time chat over WebSockets, notifications, gamification, a blog, support, an assistant, integrations and scheduled jobs. The frontend (`frontend/`) is built with Next.js and Radix UI.

See `NOTIFICATION_SYSTEM.md` for how notifications work.
